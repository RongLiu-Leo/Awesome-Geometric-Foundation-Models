# Awesome-Geometric-Foundation-Models

An illustrated guide to nine models that recover scene geometry from images and video. Follow RGB pixels through patch encoders, cross-view attention and prediction heads to see how each model produces depth, cameras, pointmaps or tracks.

## Explore the guide

Download or clone the repository, then open `index.html` in a browser. The diagrams, comparisons and code excerpts work offline. Links to papers and upstream repositories open online.

- **Roadmap** orders the papers by their first arXiv submissions and traces how ideas moved from two-view reconstruction to tracking points in 4D scenes.
- **Trace the code** on any model page to inspect its forward pass. Each step includes an explanation, original source lines and a link to the exact Git revision. **Input and output tensors** lists shapes, coordinate frames and scale conventions.
- **Compare** any two models side by side, or choose **All nine** for an overview of view fusion, geometry, scale and tracking.

## Models by first arXiv submission

- **2026** · [VGGT-Ω](https://vggt-omega.github.io/), [Déjà View](https://research.nvidia.com/labs/dvl/projects/dvlt/), [π⁴](https://yyfz.github.io/pi4/)
